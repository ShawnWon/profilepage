# Shawn XZ Wang - Portfolio & Profile

Personal portfolio and interactive resume website for **Shawn XZ Wang**, Software Developer & System Analyst.

🌐 **Live Website**: [https://shawnwon.github.io/profilepage/](https://shawnwon.github.io/profilepage/)

---

## Features

- **Interactive 3D Navigation**: Perspective 3D rotation navigation drawer built with Modernizr and CSS transforms.
- **Project Showcase**: 3D coverflow carousel (Swiper.js) featuring fullstack web and digital humanities projects.
- **Career Journey Timeline**: Interactive career and educational timeline from chemistry background to fullstack development.
- **Tech Blog Digest**: Selected Medium articles covering Cloud, GIS, Spring Boot, Ruby on Rails, and React.
- **Responsive & Animated**: Parallax background effects (Stellar.js), Waypoints animation triggers, and mobile-friendly responsive layout.

---

## Tech Stack

- **Frontend**: HTML5, CSS3 / SASS, JavaScript (ES6+), jQuery
- **UI Frameworks**: Bootstrap 3, FontAwesome 6, Icomoon
- **Libraries**: Swiper.js v8, Modernizr, jQuery Easing, Stellar.js, Waypoints
- **Hosting**: GitHub Pages

## Local Development

To view the website locally, open `index.html` directly in any modern web browser or serve it using any static HTTP server (e.g., Python `http.server` or VS Code Live Server):

```bash
# Python 3
python -m http.server 8000
```

Then visit `http://localhost:8000`.
